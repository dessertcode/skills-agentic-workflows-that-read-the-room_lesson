## Recent updates worth watching

Updated 2026-11-21. Each item links to its original source.

### GitHub Changelog

- [Pin your favorite repositories to your dashboard](https://github.blog/changelog/2026-11-20-pin-your-favorite-repositories-to-your-dashboard): use the new Favorite repositories section to choose which repositories appear on your Dashboard.
- [Improvements on the pull request overview in public preview](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview): the new pull request Overview page shows clearer merge status and next steps.
- [GitHub Desktop now supports multiple accounts per host](https://github.blog/changelog/2026-11-19-github-desktop-now-supports-multiple-accounts-per-host): sign in with more than one account on GitHub.com, GitHub Enterprise Server, or GHE.com.
- [Red Hat Enterprise Linux runner images now generally available](https://github.blog/changelog/2026-11-19-red-hat-enterprise-linux-runner-images-now-generally-available): RHEL 9 and RHEL 10 images are available for GitHub-hosted larger runners in Actions.

### GitHub Blog
